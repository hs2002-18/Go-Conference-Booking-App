# Go Conference Booking Application

A simple command-line conference booking application built in Go while learning core Go concepts such as structs, slices, functions, validation, and goroutines.

## Features

* Conference ticket booking
* User input validation
* Ticket availability tracking
* Booking information stored using structs
* Simulated ticket delivery via goroutines
* Booking summary display

## Concepts Practiced

* Variables and Constants
* Functions
* Structs
* Slices
* Loops
* Conditional Statements
* String Handling
* Goroutines
* Packages and Imports

### Prerequisites

* Go 1.21+ installed

### Execute

```bash
go run main.go
```
